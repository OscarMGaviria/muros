# Datos de entrada

## Información mínima para iniciar

| Grupo | Datos |
| --- | --- |
| Alcance | Ubicación, función, longitud, nivel requerido del estudio y entregable esperado |
| Norma | Norma estructural, de puentes o geotécnica; edición; combinaciones y estados límite |
| Geometría | Altura retenida, niveles, inclinación del relleno, espesor del fuste, ancho/espesor de zapata, puntera, talón, llave, empotramiento y juntas |
| Terreno retenido | Peso unitario seco/saturado, ángulo de fricción, cohesión justificable, fricción muro-suelo, estratigrafía y compactación |
| Fundación | Perfil, capacidad portante o resistencias nominales, fricción base-suelo, asentamientos admisibles, profundidad competente y agresividad |
| Agua y drenaje | Nivel freático, niveles extremos, permeabilidad, subpresión, dren longitudinal, filtros, barbacanas, descarga y condición de obstrucción |
| Acciones | Sobrecarga uniforme, tránsito, cargas lineales/puntuales, edificaciones, talud, sismo, barrera/impacto, equipos y fases constructivas |
| Materiales | Resistencia del concreto, fluencia del acero, pesos unitarios, recubrimiento, clase de exposición y durabilidad |
| Restricciones | Linderos, redes, excavación, servidumbres, cauces, espacio para talón, método constructivo y secuencia |

## Datos indispensables para un resultado definitivo

No cerrar como diseño definitivo sin levantamiento topográfico y sección representativa; estudio geotécnico aplicable; nivel freático y solución de drenaje; sobrecargas y acciones excepcionales; norma y edición; propiedades especificadas de concreto y acero; y evaluación de estabilidad global o insumos para realizarla.

## Preguntas compactas cuando falten datos

1. ¿Cuál es la altura retenida, la longitud y la geometría disponible detrás y delante del muro?
2. ¿Qué norma y edición deben aplicarse, y el muro pertenece a una carretera, puente, edificio o urbanismo?
3. ¿Qué parámetros entrega el estudio geotécnico para relleno y fundación, incluido nivel freático?
4. ¿Qué sobrecargas, tránsito, sismo, barrera o construcciones vecinas actúan?
5. ¿Qué resistencias, recubrimientos y condición de exposición se especifican?

Si el usuario solo busca predimensionamiento, permitir rangos claramente identificados como supuestos y acompañarlos con análisis de sensibilidad.
